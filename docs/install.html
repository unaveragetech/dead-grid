Install in four steps

  1. Download the APK

    Tap the green button above on your phone. Wait until the download finishes before you open it.

  2. Open the file

    Tap the download notification, or open the Files / Downloads app and tap DeadGrid-v….apk.

  3. Allow the install

    Android may say it blocks installs from unknown sources. Tap Settings, turn on Allow from this source for your browser or file manager, then go back. If Play Protect asks, choose Install anyway. This is a normal warning for any app that doesn't come from the Play Store.

  4. Play

    Open Dead Grid from your app drawer. Type an address or tap 📍 Use my current location, then follow the survival guide through your first day.

What it asks for

📍 Location (optional)

Only when you tap Use my current location, to put your HQ where you're standing. Say no and type an address instead. The game works the same either way.

🌐 Internet

Used to fetch map tiles and buildings (OpenStreetMap), population (US Census) and to look up addresses. There are no ads, no analytics and no accounts.

Updating

Download the newer APK from this page and install it over the old one. Your stronghold save is kept, because every release is signed with the same key. You don't need to uninstall first.

Check the download (optional)

Every release lists a SHA-256 checksum. If Android says the package "can't be parsed" or is "invalid", the download is usually incomplete. Compute the checksum of your file (sha256sum file.apk, or any checksum app), compare it with the one below, and download again if they differ.

If something goes wrong

"App not installed"

You may have an older build signed with a different key. Uninstall it first (this removes its local data), then install again.

"There was a problem parsing the package"

The download is incomplete or damaged. Check the checksum above and download again.

The map won't load

The first load needs a working connection, and the public map servers are sometimes busy. Wait a minute and try again, or try a nearby address.

Can't find the file

Look in the Downloads app, or in your browser's download list.
