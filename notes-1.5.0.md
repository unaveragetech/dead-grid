## Dead Grid 1.5.0: the long case

Android `.apk`, or play in the browser.

### What's new
- **Case 0047 is now a long story.** 20 case files, one every 10-15 nights survived (the first arrives on night 2), across about 265 nights. It builds to the truth about Harrow, Specimen 12-B and who you really are, and ends with a choice: open the gate, burn the mast, or keep the gate shut.
- **10 new defenses:** Spike Strip, Scrap Cannon, Harpoon Gun, Autocannon, Decoy Siren, Repair Pylon, Acid Sprayer, Shock Fence, Flak Battery and Railgun. Most unlock as you survive more nights. A new Gunsmith upgrade adds damage to every gun.
- **Drone roles:** set each drone as a Scavenger, Scout, Hauler, Gunship, Repair or Bomber drone.
- **Gangs are different every game,** with generated names, leaders and styles (looters, burners, drone hunters, swarms). New gangs can move in during long games. Friendly groups get varied names too.
- **New animations:** drones with spinning rotors and role colours, search lights on drones and robots searching buildings, muzzle flashes, track dust, blood and splatter.

### Fixes
- **New speed control:** a clear pause / 1× / 2× / 4× bar above the dock, replacing the old button. On a keyboard, Space pauses and 1, 2, 3 set the speed.
- **Speed no longer gets lost.** Dialogs and cutscenes pause the game on top of your chosen speed instead of overwriting it.
- Outposts no longer stay behind on blocks lost to the infection. A standing outpost now takes damage and holds the block.
- Drone launches use less fuel, and repeated messages stack instead of filling the screen.

Saves from before this version restart the case from file 1.

### Tested
- In a desktop browser: the speed bar through dialogs and pause, the new guns and drone roles in a simulated siege, the case file delivery and all the ending choices' code paths through one full ending. No script errors.
- The APK built, signed with the pinned key and passed the version check. It has not been run on a physical phone.
